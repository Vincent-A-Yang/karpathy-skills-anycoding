# Contributing

## Scope

This project is intentionally small.

Contributions should strengthen one of these areas:

- portability across AI coding tools
- clarity of the core skill
- installation simplicity
- honest compatibility documentation

## Contribution guidelines

- keep the core behavior concise
- avoid tool lock-in in the core files
- document any tool-specific assumptions explicitly
- prefer minimal adapters over large framework-specific packs
- do not add product claims without documentation or direct verification

## Pull request checklist

- the core guidance is still short and high-signal
- the change improves portability or usability
- README and docs stay accurate
- any new adapter clearly states whether it is confirmed or template-only
