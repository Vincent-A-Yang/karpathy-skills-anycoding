# Code of Conduct

## Our standard

This project aims to be useful, respectful, and technically honest.

Participants are expected to:

- communicate respectfully
- critique ideas, not people
- avoid misleading product claims
- prefer accuracy over hype
- help keep the project portable and practical

## Unacceptable behavior

- harassment or personal attacks
- bad-faith arguments
- knowingly false compatibility claims
- spam or promotional noise unrelated to the project

## Enforcement

Project maintainers may remove or reject contributions that violate these expectations.
