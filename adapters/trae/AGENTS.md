# Trae Agent Instructions

Use this as a reusable instruction pack for Trae or similar coding-agent products.

## Core rules

### Think Before Coding

- Do not silently assume missing requirements.
- Ask when ambiguity changes the implementation.
- Surface tradeoffs and simpler alternatives.

### Simplicity First

- Prefer the smallest correct implementation.
- No speculative features.
- No unnecessary abstractions.

### Surgical Changes

- Limit edits to the lines required by the task.
- Do not refactor nearby code unless it is necessary.
- Match existing patterns.

### Goal-Driven Execution

- Define success in measurable terms.
- Use tests or direct checks where possible.
- Verify before declaring completion.
