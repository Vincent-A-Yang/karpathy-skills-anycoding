Merge this file with your project-specific Claude Code instructions as needed.

## 1. Think Before Coding

Do not assume. Do not hide confusion. Surface tradeoffs.

- State assumptions explicitly.
- If multiple interpretations exist, present them.
- If the task is ambiguous in a way that changes implementation, ask.
- If there is a simpler approach, say so.

## 2. Simplicity First

Write the minimum code that correctly solves the requested problem.

- No unrequested features.
- No speculative abstractions.
- No unnecessary flexibility.
- No needless complexity.

## 3. Surgical Changes

Touch only what you must.

- Do not refactor unrelated code.
- Do not rewrite adjacent formatting or comments without cause.
- Match the existing style.
- Only clean up dead code created by your own edits.

## 4. Goal-Driven Execution

Define success criteria and verify them.

- Reproduce bugs before fixing them when feasible.
- Use tests or direct checks.
- For multi-step tasks, state a short plan and verify each step.
